# Feature Matrix

Last verified: 2026-11-10 against the code in this repository. Every row was checked by reading the owning
code path (controller/service/worker/page) and, where a test is named, that test exists and passes.

## Status legend

| Status                    | Meaning                                                                                                                                  |
| ------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| **Verified**              | Implemented and exercised by automated tests that ran against a real Postgres + Redis (AI: against the deterministic **mock** provider). |
| **Implemented, not live** | Code exists and has unit tests, but it was never run against the real external system (live LLM, SMTP server, n8n, real browser, AWS).   |
| **Partial**               | Part of the capability exists; the missing part is named in the Notes column.                                                            |
| **Not implemented**       | No code path exists. Never simulated in the UI.                                                                                          |
| **Blocked (external)**    | Needs an account, credential or provider that is not available to the project (payments, WhatsApp provider, live LLM keys, AWS).         |

Test evidence paths are relative to the repository root. `API int` = `apps/api/test/*.int-spec.ts`
(26 suites / 337 tests, run 2026-11-10), `Workers int` = `apps/workers/test/*.int-spec.ts` (4 suites / 46 tests),
`Web unit` = vitest in `apps/web` (28 files / 143 tests). Playwright journeys (`apps/web/e2e/*.spec.ts`, 6 tests)
need a running stack and `E2E_BASE_URL`; they are **not run in CI** (`.github/workflows/ci.yml` has no e2e job) and were
not re-run in this documentation pass — `task-status.md` records the last green run (2026-11-10).
